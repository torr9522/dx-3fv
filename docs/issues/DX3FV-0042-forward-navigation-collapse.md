# DX3FV-0042：转发一级导航独立折叠

- 基线：`v0.1.45-verify-chinese-display-names`
- 数据库 Schema：不变（Schema 12）
- 数据面影响：无

## 调查

桌面侧栏已经渲染单端口、隧道和多端口三个子页面，但没有子菜单状态，
所以始终展开；点击一级“转发”会跳转到 Hub。手机端只有指向 Hub 的底部
Tab，没有三个子页面的导航入口。路由和权限本身均已存在，不需要改动。

## 修复

- 一级“转发”只控制自己的子菜单，不改变其他导航或业务状态。
- 桌面和手机分别持久化展开偏好，避免一种布局覆盖另一种布局的选择。
- 当前子页面继续高亮一级和对应二级入口。
- 桌面侧栏整体收起时，点击“转发”会先展开侧栏，再显示子菜单。
- 手机子菜单显示在底部 Tab 上方，选择页面后收起，避免遮挡内容。
- 保留 `/forwards` Hub 和全部旧深链接。

## 验证

- 纯函数测试覆盖路由识别、默认状态和持久化优先级。
- TypeScript 与生产构建。
- Chromium 1440px 与 390px 实际点击、刷新、深链接、后退和前进。
- 检查页面错误、水平溢出和三个业务入口。

## 回滚

回滚到 `v0.1.45-verify-chinese-display-names`。本项仅增加 localStorage UI
偏好；旧版本会忽略新增键，不需要数据库或 Runtime 回滚。
