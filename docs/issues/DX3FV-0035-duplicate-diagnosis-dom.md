# DX3FV-0035: 规则诊断重复 DOM

## 问题

v0.1.35 首次浏览器验收时，共享诊断组件与旧规则诊断布局同时存在于 DOM。旧布局使用
CSS `hidden`，视觉上不可见，但可访问树和定位器仍能找到第二个“总测试数”，造成重复
语义和不稳定的辅助技术体验。

## 根因

0028 为降低大段 JSX 替换风险，先隐藏了旧布局，但 CSS 隐藏不是可靠的运行时卸载。

## 修复

旧布局保留为短期回滚参考，但默认状态下不进入 React 渲染树。运行时只挂载
`DiagnosisResultView`，因此可访问树、桌面和手机均只有一套诊断内容。

## 验证

- 前端生产构建通过。
- Playwright 对诊断 Dialog 中“总测试数”执行唯一元素定位。
- 单端口、隧道转发和多端口诊断均只显示公共组件。

## 回滚

切回 v0.1.35。无数据库变更。
