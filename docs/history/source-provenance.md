# 源码来源与发布血缘

DX-3FV 从 FLVX `3.0.1-rc16` Commit
`f357b30500ef99a6cf45d18f0c8a1e1881826b57`、Tree
`025c47c85613f4eba341c1e1c5fbd1a1676ca43a` 冻结开发。FLVX 派生自 Apache-2.0 的
flux-panel；DX-FV 与 ForwardX 只用于行为研究，未把 ForwardX AGPL 源码复制进项目。
内嵌 go-gost/x 来源和许可证见 `docs/gost/fork-origin.md`。

原开发仓库 RC3 为 Commit `e043e130efe878fe79350879af3bd517114bbe8c`、Tree
`865547d5f279f47c9e761c7c454bcc02f678271b`，可达 Commit 数为 1,275。公开仓库采用
sanitized publication
snapshot：原始历史含无法确认失效的上游配置候选，不会被推送。公开提交 SHA 与原始
SHA 不相同，映射必须写入发布仓库；这不是对原历史的改写或完整保留声明。
